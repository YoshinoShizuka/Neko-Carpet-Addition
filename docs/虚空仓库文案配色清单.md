# 虚空仓库 文案 / 配色清单（可直接改这张表）

## 怎么填

- **「改成」列留空 = 保持现状**，只填你想改的那些行。
- 颜色可以填 **`#RRGGBB` 十六进制**（任意颜色，不受限）或 **16 色枚举名**（见文末对照表）。
- **「文本内容」列可以直接改措辞**。`{...}` 是运行时变量（数量、页数、容量…），
  **保留占位符本身**，只改它周围的文字即可。例：`数量：{数量}` → `库存 {数量} 个`。
- **同一条文本在不同状态下颜色不同**（如翻页按钮「可用 / 不可用」），
  这类行的「改成」列请填**两个值，用 `/` 分隔**，例：`#55FF55 / #555555`。只填一个表示两态同色。
- **一行里想让前后两段颜色不同**（比如「数量：」灰色、后面的数字亮金色）：
  用 **`+`** 把片段连起来，**每个片段后面紧跟它的颜色**。详见文末「行内分段着色」。
- 只想整体调色、不改措辞的话，直接改文末 **S1–S7 语义常量**即可，一处改全局生效
  （但 S 组一旦改了，上面 A/B/C 组那些「沿用语义」的行会跟着变，两者不要重复指定）。

## 行内分段着色（一行里前后两段不同颜色）

**写法**：用 `+` 连接片段，每个片段后紧跟它的颜色。

```
`文本片段1` 颜色1 + `文本片段2` 颜色2 + `文本片段3` 颜色3
```

**例**（A1 已按这个写法落地：标签灰、数字亮金）：

| ID | 行号 | 文本内容 | 写法 | 状态 |
|---|---|---|---|---|
| A1 | 228 | `数量：` #AAAAAA + `{数量}` #FFD700 | 两段 | ✅ 已落地 |

渲染出来就是：

> <span style="color:#AAAAAA">数量：</span><span style="color:#FFD700">1,234,567</span>

**要点**：

- 片段数量不限，两三段都行。
- **空格、冒号这些分隔符要写进片段里**（上面的 `：` 就属于第一段）。
- 分段后「现在颜色」列就不用管了，以「改成」列为准。
- 不想分段的行照旧整行一个颜色。

**可分段改造的候选**（这些行天然是「标签 + 数值」结构）：

| ID | 现在文本 | 建议拆法 |
|---|---|---|
| A1 | `数量：{数量}` | `数量：` 灰 + `{数量}` 亮金 |
| A2 | `{盒} 盒 {组} 组 {个} 个` | 数字亮金 + `盒/组/个` 单位灰 |
| C17 | `已存 {种类数} 种 · 合计 {总数} 个` | `已存` 灰 + 数字亮金 + `种 · 合计` 灰 + 数字亮金 + `个` 灰 |
| C8 | `1 盒 = 27 格 × 堆叠上限（圆石 1,728 个）` | 整句灰 + 括号里的数字亮金 |

## 附加选项：去掉斜体

原版对设置了 `CUSTOM_NAME` 的物品**强制加斜体**（`ItemStack#getStyledHoverName` 字节码实证），
所以 **B1、C1、C3、C6、C12、C16 这些「物品名」一定显示为斜体**。
想要正体的话，在下面打勾：

- [ ] 全部物品名去斜体（B1 / C1 / C3 / C6 / C12 / C16）
- [ ] 全部说明行（lore）也强制去斜体
